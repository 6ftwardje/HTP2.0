# Taaktemplate

Inputs: GitHub-issue en CONTRIBUTING.md uit de repo-root.
Proces: vul TASK.md bij start en HANDOFF.md bij overdracht in. Issue/PR blijven de gedeelde bron van waarheid.
Outputs: editbare notities in de gekopieerde `.dev-work/<taakcode>/`.
Menselijke controle: eigenaar controleert scope, reviewer leest de overgenomen PR-overdracht. Vraag niet opnieuw toestemming voor gewone stappen binnen de afgesproken opdracht.
