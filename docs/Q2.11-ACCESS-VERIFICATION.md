# Q2.11 — duidelijke toegangsmelding

Issue #110; vervolg op hercontrole #95, 19 oktober 2026. Basis main 169e6dd.

De aanvullende lokale rechtenproef bevestigde dat een ingelogd gratis account voor bestaande afgeschermde content bewust op notFound uitkwam zolang betaalproducten uitstaan. Dit wijzigt uitsluitend die zichtbare weigering naar een neutrale toegangsmelding met bestaande account-/overzichtslinks. Geen contenttitel, tokens, PDF-metadata, enrichment of vervolgkaarten bij weigering. Betaalde paywall en onbekende pre-billing slug behouden hun bestaande behandeling.

- 309 tests geslaagd, inclusief beide detailingangen en beide betaalvlagstanden.
- Typecheck en productiebuild geslaagd; bestaande image-lintwaarschuwingen blijven.
- Lokale browser: free→free toegestaan, free→subscription duidelijke melding, Academy→subscription toegestaan, admin→subscription toegestaan. Onbekende slug toont de thematische ontbrekend-pagina. Next-streaming kan HTTP 200 geven voordat notFound wordt verwerkt; zichtbare toestand is daarom ook geverifieerd.
