# PDF watermark font

Noto Sans Regular, unchanged upstream binary, retrieved 18 October 2026.

Source: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

License: SIL Open Font License 1.1; full upstream copyright/license in OFL.txt.
SHA-256: `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`.

Used only on the server through @pdf-lib/fontkit and embedded as a subset. Latin/Greek/Cyrillic glyphs are supported by this font. Unavailable glyphs use an explicit U+codepoint representation in the PDF watermark; the HTML reading version keeps the Unicode profile name. The email comes from the verified Auth account. Display names are bounded to 200 codepoints for the watermark.
